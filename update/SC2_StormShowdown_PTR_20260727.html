📋 阅读备注 · Notes

本次改动旨在统一各指挥官之间的关键 timing 节点，减少不合理的早期一波压制。数值标注 加强 为增强、削弱 为削弱。时间格式为「编辑器时间【更快速度】」。

通用改动 · General Changes

机制调整 · Mechanics

经济补偿 · Economy Compensation

  • 补偿速度减缓，补偿时间从 3 分 45 秒 → 5 分 30 秒 削弱
说明：延长近一半时间以减缓早期一波 rush 情况。

压制塔 · Suppression Tower

  • 减速攻击（绿圈）恢复到 35 射程 加强

Timing 统一 · Timing Standardization

  • 部分科技时间调整，力求统一各指挥官关键 timing 节点

泽拉图 · Zeratul — 召唤瞬发

  • 移除召唤类面板的 4 秒前摇 加强（与伤害类/护盾类/治疗类面板一致）
🐛

Bug 修复 · Bug Fixes

异虫 · Zerg — 自动施法

  • 虫后孵化幼虫可自动施法 加强

神族指挥官 · Protoss

  • 修复锻炉攻防科技升级时间 Bug
  • 修复控制芯核攻防科技升级时间 Bug

指挥官平衡性改动 · Commander Changes

斯台特曼 Stetmann

  • 超级 Gary 解锁 Timing：T2 → 540 秒【386 秒，6 分 26 秒】 加强（和定身波一致）
  • 艾星超载解锁 Timing：T2 → 360 秒【257 秒，4 分 17 秒】 加强（和护盾超载一致）
  • 超级 Gary「最好的机油」叠加层数：20 层 → 10 层 削弱
  • Gary 现在可以获得「最好的机油」效果
  • 回调了超级 Gary 的 G-orb 双充能
  • 超级 Gary 的能量场技能禁用 新增
  • 机械雷兽定向潜地冲锋可自动施法 加强
  • 经济补偿：450 → 150 削弱
Gary 叠加后白值过高，提前的 Gary 不应有如此高数值；开蓝场的 Gary 带部队冲脸过于快速无敌。

诺娃 Nova

  • 护盾无人机解锁 Timing：240 秒【171 秒】 → 360 秒【257 秒】 削弱（和护盾超载一致）

阿巴瑟 Abathur

  • 愈合解锁 Timing：240 秒【171 秒】 → 360 秒【257 秒】 削弱（和护盾超载一致）
  • 愈合价格：400 / 100 → 200 / 100 加强
  • T2 共生体技能强化：50% → 100% 加强
  • 蟑螂温室四科技变异时间：110 秒【78.6 秒】 → 70 秒【50 秒】 加强
  • 强酸胆汁变异时间：120 秒【86 秒】 → 90 秒【64 秒】 加强（和扎加拉毒爆增伤统一）
  • 尖塔飞龙三科技变异时间：90 秒/90 秒/120 秒【64 秒/64 秒/86 秒】 → 60 秒/60 秒/90 秒【43 秒/43 秒/64 秒】 加强（和德哈卡统一）
  • 加压腺体（蝗虫对空）变异时间：120 秒【86 秒】 → 90 秒【64 秒】 加强（和德哈卡统一）

扎加拉 Zagara

  • 狂暴解锁 Timing：180 秒【128 秒】 → 360 秒【257 秒】 削弱（和护盾超载一致）

斯旺 Swann

  • 怨灵战机价格（按 2.5 倍攻击模计算）：128 矿 / 85 气 → 143 矿 / 95 气 削弱

德哈卡 Dehaka

  • 飞龙价格（按 1.5 倍生命值计算）：180 矿 / 112 气 → 220 矿 / 137 气 削弱
  • 格里维格的巢穴：汇聚烈焰变异时间 120 秒【86 秒】 → 60 秒【43 秒】；进化爆锤变异时间 60 秒【43 秒】 → 90 秒【64 秒】（同其他潜伏者）；建造时间 90 秒【64 秒】 → 70 秒【50 秒】
  • 穆尔瓦的巢穴：价格 200/200 → 260/260；建造时间 240 秒【171 秒】 → 180 秒【128.5 秒】
  • 达克伦巢穴：价格 200/200 → 290/290；建造时间 240 秒【171 秒】 → 60 秒【43 秒】
三大巢穴价格与建造时间均按合作原版产能/科技树成本重新精确计算。

凯瑞甘 Kerrigan

  • 移除科技研发加速，保留降价 削弱
  • 尖塔飞龙三科技变异时间：90 秒/90 秒/120 秒【64 秒/64 秒/86 秒】 → 60 秒/60 秒/90 秒【43 秒/43 秒/64 秒】（和德哈卡统一）
  • 进化狂暴变异时间：120 秒【86 秒】 → 90 秒【64 秒】；震地脊刺变异时间：120 秒【86 秒】 → 90 秒【64 秒】（和斯台特曼刺蛇/潜伏者对齐）

雷诺 Raynor

  • 大和炮研发时间：140 秒【100 秒】 → 60 秒【43 秒】 加强（修复天梯污染）
  • 休伯利安号大和炮增加伤害衰减 削弱
600 的全额 AOE 过于强大，拥有一炮决定胜负的能力。

斯托科夫 Stukov

  • 「被感染的中将」天赋不再减少亚历山大号价格和 CD 削弱
  • 感染建筑初始 CD：200 秒【142 秒】 → 240 秒【171 秒】 削弱
亚历山大号作为一次性召唤物过于强力，拥有突然袭击并摧毁敌人空军的能力。此举鼓励保存好亚历山大号。
